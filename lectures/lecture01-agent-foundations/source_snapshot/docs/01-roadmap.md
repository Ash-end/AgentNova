# 16 周学习路线

## 学习目标与节奏

以每天 2–3 小时设计，每周基础任务约 14 小时，余下最多 7 小时用于读论文、扩展实验或补课。若某周未达到验收条件，下一周先补齐，不用赶课表。

已有 Python / 深度学习基础，直接从 Agent 系统开始。Transformer 只做与推理相关的回顾；并发、持久化、隔离和性能分析按实验补齐。

CS2680 提供 Agent 到推理服务的课程主线。本表的周次、项目、练习和验收标准均为本项目自行设计；不是原课程逐讲翻译。[课程入口](https://cs2680.com/)

## 阶段关卡

**G1 / 第 3 周：理解并实现运行循环。** 能不看参考代码解释模型输出如何变成受验证的工具调用，以及工具结果如何回到下一轮。异常不靠一句 prompt 解决。

**G2 / 第 6 周：能完成真实多步任务。** 给一个代码实验任务，Agent 能理解入口、选择允许的配置、运行并核验结果；报告数字能追踪到对应运行。这个版本可能还不稳定，但已可诊断。

**G3 / 第 8 周：知道系统何时失败。** 开发集有基线，工具故障和权限场景有回归用例；分开记录模型、检索、工具、运行时和评分问题。

**G4 / 第 12 周：API 产品版。** 用户能发起、查看、取消任务；输出可核验；状态可恢复；有使用手册。多 Agent 只有在实验支持时才保留。

**G5 / 第 16 周：完整毕业。** 满足毕业任务书。若 GPU 尚不可用，API 版可以毕业，但 L13–L15 的实际服务测量必须标为“待完成”，不得把估算写成实测。

## 如何应对进度变化

- 任务做完但讲不清：追加复述和从空白实现练习，不立即学新框架。
- 概念懂但工程慢：收缩 UI，优先核心循环、工具和评测。
- 每周少于 14 小时：按任务顺延，可延长至 20–24 周。
- 每周超过 21 小时：增加对照实验和论文复现，不同时引入多个框架。
- 已选代码实验 Agent：L04 使用代码库检索，L06 使用实验与修复计划，L07 用独立测试和产物验证，L08 强化执行隔离。
- 最终项目选为数据 Agent：L04 改为 schema/文档检索，L03 强化只读 SQL 与参数验证，L07 用已知统计结果检验。

## 主线之后的 4–8 周选修

一次选一条深化路线。以下不计入 16 周必修完成条件。

| 路线 | 应先满足 | 内容 | 最终作品 |
| --- | --- | --- | --- |
| 推理与训练 | 发现可复现的工具选择或推理瓶颈，已有评测器 | Berkeley SP25；SFT、偏好优化、RL 基础、轨迹数据质量和奖励设计 | 小范围适配实验，对比 prompt / harness 改进，报告数据泄漏风险 |
| 模型底层 | 有充足时间和算力，想深入语言模型 | Stanford CS336 2025 归档课程，按 tokenizer、Transformer、训练与系统章节选学 | 实现或复现一个模型/系统模块；不预期 4 周完成整门课 |
| 浏览器与多模态 | 单 Agent 已可靠，具备环境隔离和权限设计 | Berkeley SP25 多模态讲座；网页/视觉状态、动作定位、环境重置 | 一个可复位测试站点中的浏览器 Agent |
| 生产工程 | 已有稳定用户任务及负载 | 并发任务队列、多租户隔离、版本灰度、监控、数据生命周期 | 可回滚部署、负载报告和服务故障演练 |

学习“完整”指覆盖核心能力并知道扩展方向，不代表把机器人、形式化证明、训练算法和所有框架一次学完。
